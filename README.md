# Flexprint Site

Статический сайт типографии «Флекспринт» для презентации услуг, контактов и примеров работ.

## Что внутри

- `index.html` - главная страница лендинга.
- `catalog-*.html` - отдельные страницы разделов портфолио.
- `assets/catalog-items.js` - индекс изображений для главной страницы и каталога.
- `assets/catalog/` - оптимизированные JPG-версии изображений для сайта.
- `logo.png` - логотип в шапке.
- `Machine.png` - фон блока «Производственный подход».
- `MATERIALS_INDEX.md` - автоматически собранный индекс исходных и оптимизированных материалов.
- `tools/rebuild_catalog.py` - повторная индексация исходных изображений, оптимизация JPG и генерация страниц каталога.
- `tools/build_catalog_pages.py` - генерация только HTML-страниц каталога из текущего `assets/catalog-items.js`.

## Разделы материалов

Исходные изображения разложены по папкам:

- `Круговая этикетка`
- `Офсет`
- `Самоклеящаяся этикетка`
- `Термобилеты`
- `Упаковка`

Структура подпапок используется как структура разделов на страницах каталога. Новые фотографии нужно добавлять в подходящую папку, после чего запускать повторную индексацию.

## Локальный запуск

Сайт статический, поэтому его можно открыть напрямую через `index.html`.

Если нужен локальный сервер:

```powershell
python -m http.server 8000
```

После запуска открыть:

```text
http://localhost:8000/
```

## Обновление каталога

Для полной переиндексации изображений и пересборки каталожных страниц:

```powershell
python .\tools\rebuild_catalog.py
```

Скрипт:

- находит изображения в рабочих папках материалов;
- оптимизирует их в `assets/catalog/`;
- обновляет `assets/catalog-items.js`;
- обновляет `MATERIALS_INDEX.md`;
- пересобирает страницы `catalog-*.html`.

Для пересборки только HTML-страниц каталога без повторной обработки изображений:

```powershell
python .\tools\build_catalog_pages.py
```

## Зависимости

Для `tools/rebuild_catalog.py` нужен Python и Pillow:

```powershell
pip install pillow
```

В самом сайте внешних сборщиков нет: HTML, CSS и JavaScript лежат напрямую в файлах проекта.
